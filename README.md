# mounting_reverse_engineering_project
This project is the part by part reverse engineering of AACM with models and drawings. 

This project is a full reverse engineering of AACM or adjustable angle camera mount. The original product was fully disassembled part by part and then carefully measured with standard tools such as dial calipers. The measurements then were written on the paper, representing the details real size on brief sketches and then transferred to computer CAD models. 

The project was made in 2025 for computer aided design course.

Software used: Fusion 360.
