# mounting_reverse_engineering_project
This project is the part by part reverse engineering of AACM with models and drawings. 

This project is a full reverse engineering of AACM or adjustable angle camera mount. The original product was fully disassembled part by part and then carefully measured with standard tools such as dial calibers. The measurements with details then were written on the paper, representing the details real on brief sketches and then transferred to a computer CAD models.
